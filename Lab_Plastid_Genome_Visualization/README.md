## Overview

This laboratory activity visualizes the structure and organization of the *Camellia sinensis* chloroplast genome using OrganellarGenomeDRAW (OGDRAW).

## Genome Source

The annotated plastid genome was obtained from the NCBI Nucleotide database.

**Accession:** NC_020019.1

## Software Used

OrganellarGenomeDRAW (OGDRAW)

## OGDRAW Settings

The annotated GenBank file was used as the input. A circular plastid genome map was generated with automatic inverted-repeat detection, GC content, gene transcription direction, and a full legend.

## Plastid Genome Map

The generated plastid genome map will be added here after completing the OGDRAW visualization.

## Structural Features

The *Camellia sinensis* plastid genome has the typical quadripartite organization consisting of a large single-copy (LSC) region, a small single-copy (SSC) region, and two inverted repeat regions (IRa and IRb).
